🍗 WingOps — Tablet setup

Open this page in Chrome on your Android tablet. No Python or ZIP files are needed on the tablet.

  1. Connect the tablet to the same trusted Wi-Fi as the WingOps server computer.
  2. Tap Open WingOps staff login.
  3. In Chrome tap ⋮ → Add to Home screen → Add. Name the shortcut WingOps.
  4. Tap the WingOps icon on the tablet home screen and log in with your employee ID and PIN.
